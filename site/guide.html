02 · COMPOSE

Primitive’lerle birleştirin.

Layout için container, stack, cluster ve grid kullanın. Component’leri semantic HTML içinde birleştirin.

<main class="ck-container ck-stack ck-stack--relaxed">
  <header class="ck-cluster ck-cluster--spread">
    <h1>Proje özeti</h1>
    <button class="ck-button" type="button">Yeni</button>
  </header>
  <section class="ck-grid ck-grid--3">...</section>
</main>

03 · QUALITY

Sonra kontrol edin.

Contract testleri, local browser smoke ve size gate; release öncesinde aynı komutlarla çalışır.

  1. Semantic HTML ve focus davranışını kontrol edin.
  2. 390, 768 ve 1440 viewport’larında sayfayı test edin.
  3. Minified CSS boyutunu ve generated asset’leri doğrulayın.
