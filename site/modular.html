MODULAR DISTRIBUTION

İhtiyacınız kadar CKCSS.

Basit projelerde tek dosya, kontrollü projelerde seçilebilir CSS entry point’leri, davranış gerektiğinde bağımsız Enhance modülleri.

CSS entry points

<link rel="stylesheet" href="ckcss-core.min.css">
<link rel="stylesheet" href="ckcss-layout.min.css">
<link rel="stylesheet" href="ckcss-forms.min.css">

Entry point’ler bağımlılıklarını kendileri içerir.

Enhance modules

<script type="module"
  src="/assets/enhance/navigation.js">
</script>

Modüller birbirini import etmez.

Progressive enhancement

JavaScript kapalıyken içerik, linkler ve temel form akışı korunur.
