DISTRIBUTION · v0.1.0-rc.2

CKCSS’i projenize ekleyin.

Build sistemi, npm veya zorunlu JavaScript yok. Dosyayı kendiniz barındırın ya da tag’e sabitlenmiş jsDelivr bağlantısını kullanın.

Release ZIP’i indirGitHub’da görüntüle

01 · SELF-HOST

Dosyayı sahiplenin.

Release içindeki ckcss.min.css dosyasını kendi asset dizininize koyun. En dayanıklı ve varsayılan seçim budur.

<link rel="stylesheet" href="/assets/ckcss.min.css">

Doğrudan dosyalar: ckcss.css · ckcss.min.css

02 · JSDELIVR

Tag’e sabit CDN.

Üretimde latest kullanmayın. Sürümü URL’de sabitlemek, aynı CSS’in tekrar üretilebilmesini sağlar.

<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/kayacuneyd/ckcss@v0.1.0-rc.2/dist/ckcss.min.css">

03 · MODULAR CSS

İhtiyaca göre tek giriş noktası.

Modüller kendi reset, token ve temel katmanlarını içerir. Tam paketin yerine bir giriş noktası seçin; modülleri üst üste eklemeyin.

<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/kayacuneyd/ckcss@v0.1.0-rc.2/dist/modules/ckcss-forms.min.css">

Seçenekler: core, layout, components, forms, navigation ve data. API için dokümanlara bakın.
