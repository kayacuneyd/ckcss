# Feature: Essential components

## Problem and user outcome

Developers need consistent common controls without creating unique CSS for every project.

## Scope

- Buttons, cards, badges, alerts, text inputs, selects, textareas, form feedback, and tables.
- Variants, disabled/focus/error states, responsive examples, and accessibility notes.

## Non-goals

- JavaScript state management, date pickers, custom selects, data grids, or toast queues.

## Acceptance criteria

- Each component page includes semantic HTML, states, tokens, and copyable usage.
- Buttons and controls have visible `:focus-visible` states and adequate contrast.
- Invalid form states are not communicated by color alone.
